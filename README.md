# KERUENIX — Intelligent Logistics Operating Platform

**Статус:** Discovery / System Design · **Версия документации:** 0.2 (проект) · **Дата обновления:** 7 ноября 2026 г.  
**Репозиторий:** идеи и архитектурные требования; production-система пока не реализована.

KERUENIX — логистическая платформа для экспедиторов, перевозчиков, грузовладельцев и складов. Она должна вести процесс **от запроса на перевозку и подтверждения ресурсов до исполнения, передачи груза, документов, расчётов и контроля прибыли**.

Один продукт предполагает три модели поставки: **Cloud Multi-Tenant SaaS, Dedicated Cloud, Enterprise On-Premises**. Разные компании могут взаимодействовать в одной перевозке через ограниченные и проверяемые права.

**Текущее аналитическое заключение:** [KERUENIX Project Audit 07.11.2026](docs/12-project-audit-2026-11-07.md) — фактическая готовность, пробелы, рекомендации и следующий R0a slice.

## Проектные возможности (не реализация)

- **Commercial:** RFQ, переговоры, расчёт цен, проверка контрагентов, бронирование и договоры.
- **Execution:** перевозки, грузовые единицы, автопарк, маршрут, остановки, диспетчеризация и GPS.
- **Collaboration:** взаимодействие грузовладельца, экспедитора, субподрядчика, склада и клиента.
- **Recovery:** аварийный перехват, замена машины, передача груза и документальный след.
- **Warehouse Hub:** WMS/YMS, адресное хранение, товарное соседство, cross-docking, СВХ в отдельном регламентированном контуре.
- **Cargo & Vehicle Safety:** классификация грузов, совместимость, рефрижераторы, цистерны, масса/габариты/кубатура.
- **Customer Tracking:** клиент отслеживает собственный Shipment, а не чужую машину.
- **Standards:** GS1 SSCC/GTIN/GLN, EPCIS, HS/ТН ВЭД, UN, ISO-контейнеры и региональные требования.
- **Intelligence:** сменные провайдеры маршрутов, Timefold для ограничений, Tribuo в будущем для прогнозов.

## Стратегия разработки

Первый релиз — проверяемый **сквозной автомобильный сценарий в Казахстане** с двумя независимыми tenant, подтверждёнными событиями перевозки и базовым финансовым результатом. Сложную WMS, сеть аварийного субподряда, детальную международную нормативную автоматику и ML включать поэтапно, без нарушения ядра.
