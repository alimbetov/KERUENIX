# 08 — Глоссарий KERUENIX

**Статус:** DRAFT v0.2. Использовать термины одинаково в API, UI, БД и требованиях.

| Термин | Значение |
|---|---|
| Tenant | Логическая граница подписки и безопасности в SaaS |
| LegalEntity | Юридическое лицо/филиал внутри контура клиента |
| Shipper | Грузоотправитель/сторона, передающая груз |
| Consignee | Грузополучатель |
| Forwarder | Экспедитор, организующий транспорт по коммерческому обязательству |
| Carrier | Перевозчик, фактически выполняющий транспортную услугу |
| 3PL | Оператор логистических услуг третьей стороны |
| RFQ | Request for Quotation: запрос на цену, может быть неполным |
| QuoteVersion | Конкретная версия цены/условий и времени действия |
| CarrierOffer | Предложение перевозчика; не означает подтверждённый ресурс |
| Booking | Подтверждённое договорное/ресурсное бронирование |
| Order | Коммерческое обязательство перед клиентом |
| Shipment | Отслеживаемая физическая отправка/партия |
| Consignment | Грузовая партия в конкретной договорной/транспортной семантике |
| HandlingUnit | Паллета, короб, контейнер или иная физическая логистическая единица |
| CargoUnit | Физическая учётная единица груза; граница связей с HandlingUnit фиксируется в модели |
| TransportLeg | Один этап перевозки определённым видом транспорта/исполнителем |
| Trip | Рейс конкретной транспортной комбинации, может включать несколько отправок |
| VehicleCombination | Тягач/автомобиль + прицеп/кузов/оборудование на конкретную дату |
| CapacityReservation | Подтверждённое выделение ресурса с сроком/версией |
| RoutePlanVersion | Версионированный маршрут, остановки, ограничения и ETA |
| ETA | Estimated Time of Arrival — прогноз прибытия с датой и источником |
| POD | Proof of Delivery — подтверждение доставки/приёмки |
| Custody | Фактическое хранение/ответственность за физический груз |
| Handover | Подтверждённая передача custody между участниками |
| Rescue Network | Переназначение/подхват груза при сбое перевозки, включая субподряд |
| Cross-docking | Перегрузка с входящего потока на исходящий с минимальным хранением |
| WMS | Warehouse Management System — складской учёт и операции |
| YMS | Yard Management System — территория, КПП, парковка, ворота |
| ASN | Advance Shipping Notice — ожидаемая поставка |
| Stock Ledger | Аудируемый журнал складских движений |
| RLS | PostgreSQL Row Level Security — защита выборки строк БД |
| ABAC | Attribute-Based Access Control — доступ по атрибутам, правам и ресурсу |
| ADR / ДОПОГ | Правила/соглашение об автоперевозке опасных грузов по применимости |
| UN Number | Код опасного вещества/изделия, не идентификатор паллеты |
| HS / ТН ВЭД | Таможенная товарная классификация, не GTIN |
| GS1 GTIN | Международная идентификация товарной единицы |
| GS1 SSCC | Идентификатор логистической единицы (18 цифр) |
| GS1 GLN | Идентификатор участника/локации |
| EPCIS | Стандарт обмена событиями видимости физической цепочки |
| ISO 6346 | Стандарт обозначения грузовых контейнеров |
| UN/LOCODE | Унифицированный код международных торгово-транспортных мест |
| CMR/eCMR | Международная автомобильная накладная/её электронный режим |
| TIR/eTIR | Определённый режим международного таможенного транзита |
| СВХ | Склад временного хранения при применимом таможенном регулировании |
| HOLD | Независимая правовая/качественная блокировка на выпуск |
| RuleSet | Утверждённый набор правил с источником/датой/версией |
| Timefold | Оптимизатор ограничений; не ML и не юридический источник |
| Tribuo | Java ML framework для прогнозов, не двигатель разрешений |
| AR/AP | Accounts Receivable / Payable — дебиторские/кредиторские обязательства |
| SLO/RPO/RTO | Цели доступности, допустимой потери данных и времени восстановления |

**Правило:** нельзя переводить `Shipment`, `Order`, `Consignment` и `Trip` одним русским словом «заявка» без уточнения. В UI использовать роли и состояние в бизнес-контексте.
